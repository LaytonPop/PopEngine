# M2 真实任务（靶子）

> 定于 2026-11-04。来源：`M2-任务书.md` 第〇节的候选，原样落盘。
> 用途：M2 的"真跑"必须有靶子，否则跑通了也不知道算不算通。
> 改法：**改一个字都行**，改完把下面「验收」跟着改；别只改上半截。

## 规格

```
输入：一个仓库路径（先只支持本地路径，不做 git clone）
工具：list_dir(path) / read_file(path)
输出：固定 JSON
      {"name": ..., "one_liner": ..., "language": ...,
       "top_dirs": [...], "entrypoints": [...]}
验收：对 2 个不同仓库各跑一次，输出都是合法 JSON、字段齐全
```

## 判据（定了就别再动）

- **一屏说得清**
- **输出能给断言**：五个字段都能程序化检查，不靠"看着像"
- **说不出"模型必须调哪几个工具"＝还没定**

## 验收的三个断言（可直接进测试）

1. `json.loads(output)` 成功，且五个键齐全、类型对（`top_dirs` / `entrypoints` 是 list[str]）
2. trace 里至少出现一次 `list_dir`，且**由模型决定**（不是代码里写死顺序）
3. 换一个仓库再跑一次，同样合法（证明不是在背第一个仓库的答案）

## 两个靶子仓库（建议）

| 用途 | 候选 | 为什么 |
| --- | --- | --- |
| 小的、结构干净 | `D:\workSpace\Pop\PopEngine`（本项目自身） | 目录浅、README 有、能人工核对输出对不对 |
| 中等、真实外部项目 | 任选一个已 clone 的仓库（如 `D:\workSpace\wen\Repository\ChatBox`） | 证明不是只对自家结构有效 |

## 不做（照 `02-阶段0-一页纸.md` 的冻结清单）

不做 git clone、不做递归遍历整棵树、不做 RAG/MCP/前端、不做缓存与重试。
**工具只有两个**：`list_dir` / `read_file`。要加第三个，先回来改这份文件。
